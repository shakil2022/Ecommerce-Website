# University Cafeteria Management System

A full-stack web-based **University Cafeteria Management System** designed to simplify food ordering, cafeteria operations, inventory, payments, delivery, and customer feedback.

## 🚀 Features

* 👤 **Customer:** Browse menu, place/customize orders, view history, favorites, and feedback.
* 🛡️ **Admin:** Manage users, food items, menus, orders, inventory, and reports.
* 👨‍💼 **Manager:** Manage staff schedules, sales, menus, promotions, and feedback.
* 💵 **Cashier:** Handle payments, POS operations, refunds, and customer support.
* 🛵 **Delivery:** Manage deliveries, track orders, and update delivery status.

## 🧩 Key Modules

* Food & Menu Management
* Order Management
* Inventory Management
* Payment & Refund Management
* Delivery Tracking
* User & Role Management
* Sales & Revenue Reports
* Customer Feedback & Ratings

## 🛠️ Technology Stack

**Frontend:** React, Redux, JavaScript
**Backend:** Node.js, Express.js
**Database:** MongoDB, Mongoose
**Architecture:** REST API & Role-Based Access Control

## ⚙️ Installation

```bash
git clone https://github.com/shakil2022/Ecommerce-Website.git
cd Ecommerce-Website
```
